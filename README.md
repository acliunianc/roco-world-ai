# 洛克王国世界-AI

本应用使用 rust 编程语言进行开发，使用 `dioxus` crate制作桌面应用程序

接入大语言模型，用于游戏内自动进行PVP战斗功能



## 功能

### 无需打开游戏部分

- AI对战：两个AI进行战斗，产生战斗日志用于AI学习
- 人机对战：检验AI学习成果，提升人类技术水平



### 需要打开游戏部分

- AI自动进行PVP



## 需要的工具

1. 图片识别（识别当前我发上场精灵和敌方上场精灵）
2. 知识库（./data/*）
3. OCR（读取战斗日志，分析使用的技能）
4. 鼠标键盘操作自动化库（帮我释放技能）
5. 大语言模型（根据游戏规则，分析下一步怎么做收益最大）
6. 开发由语言模型驱动的应用程序的框架（将以上工具整合给大语言模型）
